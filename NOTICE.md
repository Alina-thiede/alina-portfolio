# Notice

This repository is a **portfolio**. The projects documented here are work samples,
published to show how something was designed and built. They are not products, not
templates, and not maintained for reuse.

**No source code is published here.** Code excerpts in these write-ups are short,
abridged illustrations, included as evidence for the claims around them.

The applications themselves run privately — inside company tenants, behind
company sign-in, on real client data. They are not publicly reachable, and that
is deliberate.

No credentials, connection strings, workspace identifiers, server names, client
names or real working-time data appear anywhere in this repository. Every figure,
project name, hour and euro amount in the text and in the screenshots comes from
an invented demo dataset — in the work hour tracker, every demo time entry labels
itself with a `[DEMO]` prefix, which is why the screenshots can be published at all.
